01. about_me

Most of my experience is in space systems. As an undergrad I wrote production Python for Auburn's student satellite program, then built flight software for the Alabama CubeSat Initiative — an autonomous agent trained with CMA-ES to make real-time decisions on a payload with almost no compute or memory, plus the encrypted APIs that let onboard subsystems talk to each other.

I'm now pursuing an M.S. in Cybersecurity Engineering, with coursework in threat modeling, secure software processes, digital forensics, and reverse engineering. I also earned an Undergraduate Certificate in AI Engineering alongside my B.S. in Computer Science.

Outside of class I build AI projects — a CNN agent that plays a platformer from raw pixels, and a private desktop assistant that runs LLMs locally. I also TA for 40+ students a week, which keeps me sharp on explaining things clearly.

03. projects

Featured · open source

Hearth

A desktop AI assistant that runs entirely on your own machine. A Gradio chat UI talks to a FastAPI backend, which manages a local LLM through LM Studio (or any OpenAI-compatible server) and streams responses back. The assistant can read a region of the screen with OCR and computer vision, and it's extensible through a plugin system.

  • No cloud APIs — prompts, screen captures, and settings never leave the device
  • Settings encrypted at rest with Fernet
  • Backend auto-starts on demand and detects an already-running model server
  • Python
  • FastAPI
  • Gradio
  • LLMs
  • OpenCV
  • OCR
Full-stack · mobile web app

LifeCal

A calendar, to-do, and habit app built for my phone and installable as a PWA. It pulls my whole schedule into one place: two-way sync with Google Calendar and Outlook, read-only subscriptions to Canvas, iCloud, or any ICS feed, and Canvas assignments that show up as to-dos before they're due.
