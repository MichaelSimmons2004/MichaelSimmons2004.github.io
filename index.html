Independent research · ongoing

MoE Inference on Consumer GPUs

An inference engine that runs large mixture-of-experts language models, up to 80B parameters, at their original FP8 precision on a single 12–24 GB consumer GPU.

  • No quality loss: matched the unrestricted model on HumanEval (152/164 vs. 151/164) with frozen weights and no fine-tuning, and measured fidelity against the native model with KL-divergence evaluation.
  • Fast on modest hardware: ~26 tokens/s on a 30B MoE model and ~21 tokens/s on an 80B MoE model on an RTX 4070 (12 GB).
  • Wrote custom FP8 GPU kernels in Triton; performance work with torch.compile and CUDA graphs.
  • 150+ tests validate output against the reference Hugging Face transformers implementation across six MoE model families, on CPU and GPU.
  • ~230 experiments in v1, then a v2 rewrite into a clean, installable package with a CLI for planning, chat, generation, benchmarking, and evaluation.
  • Python

LifeCal

An invite-only calendar, to-do, and habit app, installable as a PWA and in daily use by 5 people. About 33k lines of TypeScript across 23 feature modules, built in 19+ planned phases that each shipped a migration, unit tests, end-to-end coverage, and a commit.

  • Security review (self-conducted, documented): audited all 18 server routes, redirects, RLS policies and grants, security-definer functions, account-deletion cascades, abuse limits, headers, dependencies, and secrets.

  • Per-user isolation via row-level security on all 28 tables; invite gate enforced in the database.
  • Two-way Google Calendar and Outlook sync over OAuth 2.0 with push webhooks (per-channel secrets, encrypted token storage); ICS/Canvas feeds refreshed every 30 minutes with pg_cron.

Hearth

A private desktop AI assistant that runs entirely on-device. A Gradio chat UI talks to a FastAPI backend, which drives a local LLM through LM Studio or any OpenAI-compatible server and streams the responses back.

  • Privacy by design: no cloud APIs. Prompts, screen captures, and settings never leave the device, and settings are encrypted at rest with Fernet.
  • Agent loop with a tool runner, token-aware context management, and a plugin system for extensions.
  • Reads a region of the screen with OCR and computer vision; can watch terminals and files and control a browser through the Chrome DevTools Protocol.
  • Backend starts on demand, discovers an already-running model server, and monitors VRAM and memory use.
