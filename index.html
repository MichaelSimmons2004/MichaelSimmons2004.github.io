02. projects

Featured project

CLIHBot

A desktop AI assistant that runs entirely on your own machine. A Gradio chat UI talks to a FastAPI backend, which manages a local LLM through LM Studio (or any OpenAI-compatible server) and streams responses back. The assistant can look at a region of the screen using OCR and computer vision, and it's extensible through a simple plugin system.

  • Backend auto-starts on demand and auto-detects an already-running model server
  • Screen observation with PyAutoGUI, OpenCV, and Tesseract OCR — processed locally
  • User settings stored encrypted at rest (Fernet)
  • Session management, prompt templates, and a tool/plugin layer
